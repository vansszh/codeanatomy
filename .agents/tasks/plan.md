# Implementation Plan

## Project Context

**CodeAnatomy** is a Flask web app for Python complexity analysis. No build step — templates are server-rendered, and the browser loads ES modules directly. The project uses:
- Flask backend (app.py)
- Vanilla JS/CSS frontend (no external libraries)
- Design tokens in tokens.css (black theme, accent colors)
- Two pages: home (index.html) and analysis (analysis.html)

**Key constraints:**
- NO git commands
- NO external libraries (Prism, CodeMirror, etc.)
- Do NOT modify tokens.css or base.css
- Keep existing API endpoints and studio.js/motion.js unchanged
- The runner in studio.js uses `[data-input]` textarea, `[data-run]` button, `[data-report]`, `[data-state-empty]`, `[data-state-working]`, `[data-state-error]` selectors — these data attributes MUST remain

**Verification:** Open the Flask dev server at http://127.0.0.1:5000, manually test the UI changes in a browser.

## PART 1: Analysis Page Redesign

### Design Decisions

**Syntax highlighting approach:** Use a dual-layer system — the existing `<textarea data-input>` stays functional for studio.js, but we overlay a `<pre><code>` element with syntax-highlighted HTML on top. The textarea becomes transparent (color matches background), and the overlay provides the visual highlighting. Line numbers go in the existing `.line-gutter` which already exists in the layout.

**Layout shift:** Remove the two-column grid (`.code-space` currently uses `grid-template-columns: minmax(0, 0.92fr) minmax(0, 1.08fr)`). Change to single column, full width. The page body gets `overflow: hidden`, only `.code-surface` scrolls. Results will be appended BELOW the code panel in the same flow.

**Loader design:** Full-screen fixed overlay with `backdrop-filter: blur(8px)`, centered animated loader using CSS keyframe rings (three concentric circles pulsing). JS shows/hides this overlay.

**Results layout:** After analysis, hide the empty/working states, show results BELOW the code panel. Use cards for summary, complexity bounds, drivers, notes — same structure as current `.report` but refined spacing.

**Hero section:** Larger, bolder headline (increase font size), add visual elements (code-inspired graphics, geometric shapes using SVG or CSS), better spacing. Use existing accent colors.

**Feature highlights:** Replace the current `.detail-grid` with a more engaging layout — larger icons, hover effects, better typography. Add SVG icons for each feature (trace, cases, assumptions).

**Visual interest:** Add subtle geometric/code elements as decorative background (CSS pseudo-elements with gradients, shapes). Hover animations on cards and links (translate, scale, glow). Better use of whitespace and rhythm.

## Summary

This plan transforms the CodeAnatomy UI with:
- **Analysis page:** Syntax-highlighted code editor (overlay approach), single-column non-scrollable body, full-screen blur loader, results below code in structured cards
